## 📖 About

This repository contains a structured **SCCM / Microsoft Endpoint Configuration Manager** learning path from **Beginner to Advanced**.

The course is divided into:

- 🟢 **Beginner** → Modules 1–6
- 🟡 **Intermediate** → Modules 7–11
- 🔴 **Advanced** → Modules 12–14

The material covers SCCM architecture, site deployment, client management, inventory, software deployment, software updates, OSD, endpoint protection, compliance, MDM, power management, remote control, backup/recovery, monitoring, and secondary sites.
